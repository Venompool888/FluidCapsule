# FluidCapsule 1.4.0

## 中文

- 全新 Material Design 3 + Jetpack Compose 界面重构：新增“概览 / 应用与规则 / 历史 / 设置”四标签导航、实时胶囊沙盒预览（支持隐私与时长即时联动真机测试通知）、5 通道健康诊断，以及历史关键词搜索和 Material You 动态取色开关，同步重写白名单、单应用规则与短信云同步设置页。
- 强化内建短信与邮件验证码规则：新增支持 `3-3` 连字符字母数字码（如 Slack）、`Your ... code to link/verify ... is:` 账户绑定验证码（如 Afterpay）、跨句长正文验证邮件（`Here is the code ...`）与短句 `Use/Enter code ... to log in`，并屏蔽英文序数日期（如 `31st`）、时间单位词（如 `10mins`）及促销兑换码误报。
- 强化验证链接与登录引导识别：新增魔法/安全登录按钮 CTA、重置密码按钮 CTA 与直链绑定，并过滤两步验证已开启提醒、线下证件核验通知及月结单“点击链接或登录”等误识别场景。
- 重要升级提示：本版本采用新的正式发布签名密钥构建（发布包提供 `SHA256SUMS.txt` 用于校验）。从 `v1.3.0` 及更早版本升级时，请先在旧版中通过“导出 JSON 备份”保存通知历史，卸载旧版本后再安装 `v1.4.0` 并导入备份恢复，后续同签名版本即可直接原位覆盖升级。

## English

- Full Material Design 3 and Jetpack Compose UI redesign featuring four-tab navigation (Overview, Apps & Rules, History, Settings), an interactive live capsule sandbox preview with real test notifications, five-channel health diagnostics, History keyword search, Material You dynamic color toggle, and redesigned Whitelist, App Rule, and Cloud Sync settings screens.
- Upgraded built-in SMS and email OTP parsing rules: supports hyphenated `3-3` alphanumeric codes (such as Slack), `Your ... code to link/verify ... is:` account-linking codes (such as Afterpay), separated long-form verification emails (`Here is the code ...`), and concise `Use/Enter code ... to log in` prompts, while filtering ordinal dates (`31st`), duration/unit tokens (`10mins`), and promo redemption codes.
- Upgraded verification and sign-in link parsing: recognizes magic sign-in button CTAs, password-reset button CTAs and direct reset URLs, while suppressing informational 2-Step Verification notices, in-person ID collection reminders, and statement navigation prompts.
- Important upgrade note: `v1.4.0` is signed with a new release keystore (`SHA256SUMS.txt` is attached for APK verification). When upgrading from `v1.3.0` or earlier, export your Notification History as a JSON backup first, uninstall the previous build, install `v1.4.0`, and import the backup back.
