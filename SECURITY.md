# Security policy

FluidCapsule handles notification content and therefore treats privacy regressions as security issues.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature under the repository's **Security** tab. Do not include real notification text, OTPs, account identifiers, avatars, device serials, IP addresses, or access tokens in a public issue.

If private reporting is unavailable, open a public issue containing only a minimal, fully synthetic reproduction and ask the maintainer for a private contact channel.

## Supported versions

Until the first stable release, only the latest commit on the default branch is supported.
