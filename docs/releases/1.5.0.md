# FluidCapsule 1.5.0

## 中文

- 移除主界面 4 个标签页的固定吸顶顶栏：概览、应用与规则、历史与设置顶部区域现在均随页面内容自然滚动，边缘留白更舒展，减少顶部栏长期占位。
- 精简概览与设置分工，消除重复信息：
  - **概览**改为顶部核心状态横幅（未完全就绪时提供单行跳转到「设置」）、2×2 核心能力卡片、单行 **发送测试验证码** 卡片（按系统原生样式弹出并遵循当前隐私设置）与最近活动摘要，移除跨机型形态各异的胶囊预览模拟框和重复的 5 项权限展开卡。
  - **设置**作为权限与后台保活唯一权威入口（状态点 + 一键跳转），移除与概览重复的最近活动区块，精简短信云同步卡片，并在页面底部新增 **GitHub 项目仓库** 入口（直达 `Venompool888/FluidCapsule` 查看开源说明与下载新版）。
- 降低 **应用与规则** 列表信息密度：顶部集成紧凑计数栏、刷新排序与词库版本入口；合并默认短信说明与云同步短信规则为双行紧凑卡（仅在未筛选时展示）；普通应用隐藏包名（搜索输入 `.` 时自动显示包名），已启用或已配置专属规则的应用以紧凑单行摘要呈现并支持右侧一键微调规则。
- 升级提示：本版本沿用与 `v1.4.0` 相同的正式发布签名密钥，从 `v1.4.0` 可直接原位覆盖安装升级，完整保留现有通知历史与全部配置。

## English

- Removed sticky top app bars across all four main tabs (Overview, Apps & Rules, History, and Settings): header areas now scroll smoothly with page content while preserving clean edge-to-edge status bar spacing.
- Deduplicated Overview and Settings responsibilities:
  - **Overview** now features a scrollable brand header, a compact single-row status/permission banner (jumping directly to Settings when local permissions are missing), the 2x2 capability tiles, a streamlined single-row **Send Test Verification Code** card replacing the simulated capsule preview, and Recent Activity.
  - **Settings** serves as the single authoritative Permissions & Keep-Alive Hub (removing the duplicate Recent Activity card, tightening the Cloud Sync card layout, and adding a bottom **GitHub Repository** entry linking to `Venompool888/FluidCapsule`).
- Reduced visual density in **Apps & Rules**: folded refresh and rules-pack pill into a scrollable top utility strip, combined default SMS info and cloud SMS rule into a compact dual-row card when unfiltered, hid raw package names by default (auto-revealed when the search query contains `.`), and replaced multi-row rule chip blocks with concise single-line rule summaries.
- Upgrade note: `v1.5.0` is signed with the same official release keystore as `v1.4.0`, so `v1.4.0` users can update directly in-place without losing notification history or settings.
